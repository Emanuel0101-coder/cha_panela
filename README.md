
# Chá de Panela

Site interativo para confirmação de presença e escolha de presentes.

## Tecnologias

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Instalação

1. Clone o repositório.
2. Crie um ambiente virtual:

   python -m venv venv

3. Ative o ambiente:

   venv\Scripts\activate

4. Instale as dependências:

   pip install -r requirements.txt

5. Execute:

   python app.py

6. Acesse:

   http://127.0.0.1:5000
